# LX Music iOS 二改 · 项目架构指南

> 这套指南写给「第一次接手这个项目的人」：假设你没参与过开发，从零开始理解这个代码库。
>
> 全部内容基于对工作副本 `LX-Y-Music-IOS-test-sea`（分支 `ios-adaptation`，代号 Sea）的逐子系统代码审计：共 885 个源文件、约 10.4 万行 TS/TSX 与 145 个原生文件、约 2.2 万行原生代码。文中所有结论都标注了代码出处（文件路径 + 符号名）；代码无法证实的事项会明确写「未确认」，不臆测。统计与审计日期：2026-11-08。

## 推荐阅读路径

- **新人接手**：01 → 02 → 03 打底，再按你要改的模块进 04–08，最后看 10 了解二改的历史包袱。
- **改 WebDAV 相关功能**：05 与 06 连读（共用凭据、互相调用），再看 02 的事件中枢部分。
- **查「为什么代码要这样写」**：各章末尾的「设计与坑」小节 + 10 章索引——这个项目大量防御代码对应真实事故，删改前务必先看。
- **构建与发版**：直接看 09。

## 约定

- 文中「设置键」指 `LX.AppSetting` 的点号键（如 `sync.webdav.url`），默认值出处统一为 `src/config/defaultSetting.ts`。
- 「存储键」指持久化键（如 `@webdav_music_config`），总账在 03 章 3.4 节。
- 行数、文件数均为审计当日实测；引用行数的文件在正文会给出路径，可自行复核。
