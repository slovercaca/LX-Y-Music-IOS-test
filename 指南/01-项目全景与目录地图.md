# 01 · 项目全景与目录地图

> 本章给第一次接触这个项目的人一张地图：这是什么、技术栈是什么、代码都在哪、每个子系统负责什么。所有数字为 2026-11-08 对工作副本 `LX-Y-Music-IOS-test-sea`（分支 `ios-adaptation`）的实测统计。

---

## 1.1 这是什么

一个 React Native 写的第三方音乐播放 App（LX Music 的 iOS 适配分支），聚合多个平台（网易 wy / QQ tx / 酷狗 kg / 酷我 kw / 咪咕 mg）的搜索、歌单、排行榜与播放，支持：

- 多音源（含用户自定义 JS 音源脚本）取播放地址/歌词/封面；
- 本地歌单管理、平台歌单浏览、每日推荐、播放历史；
- 歌曲下载到本地库（带歌词/封面/标签写入）、离线模式；
- **WebDAV 云盘曲库**：把自己的 WebDAV 服务器当曲库在线点播与上传（二改新增）；
- **WebDAV 数据同步**：歌单/设置/音源跨设备同步，带多服务器故障转移（二改新增）；
- 液态玻璃风格的主题 UI（16 套主题、动态背景）。

上游血统：`Q-1515/lx-music-mobile` → `1970905901/LX-Y-Music-IOS`（iOS 适配）→ 本分支二改。许可证 Apache 2.0。仓库 `slovercaca/LX-Y-Music-IOS-test`，包名 `lx-music-mobile`，`package.json` 的 version 为 `20260825`（日期式版本号）。

## 1.7 读代码的推荐顺序

1. 先读本指南 02 章的启动时序，顺着 `src/app.ts` → `core/init/index.ts` 把初始化链走一遍；
2. 再读 03 章，搞清「状态在哪、怎么改、怎么订阅」这三件事，后面所有子系统都建立在这套机制上；
3. 按兴趣进 04（播放/数据）、05+06（WebDAV 两件套，建议连读）、07（界面）；
4. 遇到原生行为（上传进度、锁屏歌词、玻璃渲染）查 08 章；要构建/发版查 09 章；
5. 想知道「为什么代码长这样」，各章末尾的「设计与坑」与 10 章的二改索引是最有价值的部分——这个项目的大量防御代码都对应真实事故，删改前先看注释与本指南的出处说明。
